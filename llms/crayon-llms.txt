# Crayon

> Crayon (crayon.co) is a competitive intelligence platform that automatically captures, analyzes
> and distributes competitor activity — website and pricing changes, social posts, news, reviews,
> job postings — into battlecards, win/loss stories, competitor profiles and sales enablement
> content for go-to-market teams. Its one machine-callable surface is a hosted MCP server.
>
> NOT to be confused with Crayon Group ASA (crayon.com), an unrelated Norwegian Microsoft CSP and
> software asset management company whose API lives at api.crayon.com / apidocs.crayon.com.

Generated by API Evangelist from the public Crayon surface on 2026-08-14. Crayon publishes no
llms.txt of its own (https://www.crayon.co/llms.txt returns 404). This is an independent
third-party index, not a Crayon document.

## Callable surface

- [Crayon MCP server](https://mcp.crayon.co/mcp/): Hosted Model Context Protocol endpoint
  (JSON-RPC over Streamable HTTP). Requires OAuth 2.1; anonymous `tools/list` returns HTTP 401.
  POST to the path WITH the trailing slash — `/mcp` 307-redirects to `/mcp/`.
- [OAuth protected-resource metadata](https://mcp.crayon.co/.well-known/oauth-protected-resource/mcp/):
  RFC 9728 document naming https://app.crayon.co/ as the authorization server.
- [OAuth authorization-server metadata](https://mcp.crayon.co/.well-known/oauth-authorization-server):
  RFC 8414 document. Authorization code + refresh token, PKCE S256, dynamic client registration,
  single scope `mcp:read`.

## Not published

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI or JSON Schema on any crayon.co host.
- No developer portal or API reference. `api.`, `docs.`, `developer.`, `developers.`, `status.`,
  `trust.` and `security.crayon.co` are wildcard DNS answering with the marketing homepage.
- No public pricing, rate limits, changelog, status page, SLA, deprecation policy, security.txt,
  A2A agent card, SDK or CLI.
- The Content API and Answers API Crayon markets are announced in blog posts only; no endpoint,
  authentication model or reference is published for either.
